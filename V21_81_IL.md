# Şehir Hikâyeleri V21 — 81 İl Kataloğu ve Tekrarsız Görseller

81 il tek `lib/src/data/city_catalog.dart` dosyasına açıkça yazıldı. Oyun ve
şehir seçim ekranındaki görüntü sağlayıcıları bu dosyadaki her il için **ayrı**
resim yolunu kullanıyor. Önceki sürümün bölgeye özel tek resmini bütün illerde
tekrarlayan yedek mekanizması kaldırıldı.

## Bölüm ve kayıt güvenliği
- Eski 6 ilin orijinal bölüm indeksleri: 0–17.
- Eski 12 ek bölüm indeksi: 18–29 (değişmedi).
- Sonradan eklenen 75 il: 30–254.
- **81 × 3 = 243 ana bölüm, 12 ek bölüm; toplam 255**.
- `coins`, `unlocked_v3`, `current_level_v3`, `finished_levels_v3`,
  `solved_v3_*`, `hints_v3_*`, `chapter_schema`, `adv15_*` anahtarları değiştirilmez.
- Kilitler kalıcı sabit `locked:true` değerlerinden değil, kaydedilmiş ilerlemeden hesaplanır.

## Görsel durumu — dürüst bilgi
- İlk 6 ilin mevcut görselleri korunur.
- V20'deki **19** il için ayrı yüksek kaliteli kart (1200×650) ve sahne (900×1600) dosyaları kullanılır.
- Daha önce hazırlanmış yüksek kaliteli kartların bulunduğu bazı illerde mevcut ayrı kart görselleri korunur.
- Diğer illerde ise `assets/images/provinces/<slug>.webp` altında **ille özel ayrı bir illüstrasyon** kullanılır.
- Bu illüstrasyonların her biri ayrı dosyadır fakat resmî fotoğraf veya gerçek
  şehrin yer işaretini birebir yansıtan HD fotoğraf *değildir*.
- Hepsi için doğrulanmış yüksek kaliteli fotoğraf arşivi oluşturulması ayrıca gereklidir.

## GitHub yükleme — Termux'ta tek komut

Önce ZIP'i telefonunun Downloads klasörüne kaydet.

```bash
cd ~/kelime-cemberi && cp kelime_main.dart kelime_main_v20_yedek.dart && unzip -o ~/storage/downloads/kelime-sehirleri-v21-81-il-tam.zip -d . && git add kelime_main.dart lib pubspec.yaml assets README.md V21_81_IL.md && git commit -m "V21 tum 81 il ayri arka plan" && git push origin main
```

Arşiv GitHub Actions `.github/workflows` dosyalarını değiştirmez.
GitHub Actions'ta yeni APK derlemesini ve 81 şehir kartını kontrol et.

**Gerçek cihazda Flutter/Android build testi yapılmadı** (bu ortamda Flutter SDK yoktur).
Uygulamayı kaldırmadan aynı imza ve paket kimliğiyle güncelle.
