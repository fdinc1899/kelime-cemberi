# Kelime Çemberi V32.5 — Macera Merkezi Tema Renkleri

**Ne değişiyor?** Macera Merkezi başlığında sağ üstte renk paleti butonu.
Beş ön ayar: Lacivert–Altın, Zümrüt, Mor Gece, Bordo, Okyanus.
Palet Macera Merkezi üst panelinde ve temel Günlük/Pasaport/Yolculuk
bölümlerinde uygulanır. Bazı eski V31/V32 alt ekranlarının sabit renkli
kartları henüz bu seçime bağlı değildir. Oyunun ana menüsü ve harf çemberi
teması ayrı kalır. Seçim `v325_adventure_palette` anahtarıyla kaydedilir.

**Yükleme:** Bu ZIP dosyasını telefonun İndirilenler klasörüne indir.
Termux aç ve aşağıdakini tek seferde yapıştır:

```bash
cd ~/kelime-cemberi && unzip -o ~/storage/downloads/kelime-cemberi-v32-5-tema-renkleri.zip -d . && bash V325_GITHUB.sh
```

**Önemli:** Bu paket V31.8 tasarımını ve V29 Macera Merkezi'ni
gerektirir. V32.4 harf çemberi temasına dokunulmaz. İlgili dosya yerleşimi farklıysa kurulum eski
kaynakları değiştirmeden durur. Oyun kayıtlarını silmez. GitHub Actions
yeşil tik gelmeden APK derlemesi doğrulanmış değildir.
